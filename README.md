# cacika-sample-todo

[cacika](https://cacika.net) の「リリース進行（β版機能）」の集計を試すためのサンプルのうち、Todo List 本体の開発 issue と PR（PR の本文に「Closes #開発 issue 番号」を書く） を置くリポジトリです。

全体の構成と、集計に乗せるためのルール・config.yaml の例は [wheatandcat/cacika-sample-spec](https://github.com/wheatandcat/cacika-sample-spec) の README を見てください。

## 動かし方

`index.html` をブラウザで開くだけで動きます。
